# Student Marks Analysis

A Python project that analyzes student marks, calculates the best two mid-exam scores, generates total marks and grades, and visualizes performance using charts.

## Features
- Load student marks data from a CSV file
- Handle missing values
- Calculate the best 2 mid-exam scores for each subject
- Compute total marks for every subject
- Assign grades based on total marks
- Generate pie charts and bar charts for performance analysis
- Export the processed dataset to a new CSV file

## Technologies Used
- Python
- Pandas
- Matplotlib
