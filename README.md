# Student Marks Analysis

This project analyzes student marks using Python, Pandas, and Matplotlib. It calculates the best two mid-exam scores for each subject, generates total marks and grades, and provides visual insights through charts.

## Features

- Load student marks data from a CSV file
- Identify and handle missing values
- Calculate the best 2 out of 3 mid-exam scores
- Compute total marks for each subject
- Assign grades based on total scores
- Generate pie charts for subject-wise average marks
- Generate bar charts for grade distributions
- Export the final analyzed dataset to a CSV file

- IT

- Python
- Pandas
- Matplotlib

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/student_marks_analysis.git
   ```

2. Navigate to the project directory:
   ```bash
   cd student_marks_analysis
   ```

3. Install the required libraries:
   ```bash
   pip install pandas matplotlib
   ```

## Usage

Run the Python script:

```bash
python student_marks_analysis.py
```

## Output

The project generates:

- Subject-wise total marks
- Subject-wise grades
- Average marks distribution pie chart
- Grade distribution bar charts
- Processed dataset saved as:

```text
student_marks_final_analysis.csv
```
